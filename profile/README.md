**Kintsugi** — a safety layer for AI coding agents. Warns before destructive
commands run, makes them reversible, and keeps a tamper-evident record of
everything every agent did.
[Website](https://kintsugi.tools) · [Install](https://kintsugi.tools/install.sh)

**Paper** — local-first document search with exact page and line citations.
One binary: CLI + MCP server. PDF, DOCX, 15+ formats, OCR for scans, no
cloud, no telemetry.
[Website](https://kintsugi.tools/paperscope.html) · [Install](https://kintsugi.tools/paper.sh)
