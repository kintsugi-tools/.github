# Contributing

Thanks for considering it. Before you invest time:

1. Open or comment on an issue describing the change, so we can agree on
   the approach.
2. Fork, branch, commit with a clear message.
3. Keep changes focused: one concern per pull request.
4. Match the existing code style; CI runs fmt + clippy with `-D warnings`.

By contributing you agree your work is licensed MIT OR Apache-2.0, the
same as the repository.
